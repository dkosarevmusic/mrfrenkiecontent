# Добавить видео (пачкой, раз в месяц)

Файл: трекер `<obsidianVault>/Life Manager/MDs/MrFrenkie Content.md` (`obsidianVault` — в `~/.claude/machine.json`). UTF-8, переводы строк LF — сохраняй так же. Frontmatter, кнопки и счётчики над списком не трогай. Читай по частям: `Grep "^(#|>)"` → карта разделов.

## Разметка списка
- Уровни: `# 🎛️ Раздел` → `## 🥁 Подраздел` → `> [!info] Название` → `> > [!example] Название` → `> > ##### Название`.
- Видео: `- [ ] [Название](ссылка)` с префиксом `>` своего уровня. Есть и Boosty, и YouTube → `- [ ] [Название](boosty) ([YouTube](youtube))`. В списках без чекбоксов (пресеты, Scripts) — без `[ ] `: повторяй соседей.

## Метка 🆕 — правило
- Видео: `🆕` вплотную перед `[`: `- [ ] 🆕[Название](ссылка)`.
- Заголовок с эмодзи: `🆕` вплотную перед эмодзи, без пробела: `## 🆕🥁 Drum Synthesis`. Между эмодзи и названием ровно один пробел.
- Выноска или заголовок без эмодзи: вплотную перед названием: `> > [!example] 🆕Snare`, `> > ##### 🆕Common`.
- Помечается **каждый уровень** от `#` до раздела, где лежит новое видео: например, `#`, `##`, `[!info] Videos`, `[!example] Snare`.

## Шаги
1. **План.** Дмитрий даёт пачку ссылок и разделы. Названия нет → спроси (Boosty по подписке не открывается). Grep каждой ссылки (id поста или видео): уже есть → скажи где. Покажи таблицу «видео → полный путь раздела» и жди «да». Раздел не назван или неясен → спроси, сам не выбирай. Нужен новый раздел → уточни название, уровень и место.
2. **Копия.** У хранилища нет git: скопируй трекер в scratchpad до правок.
3. **Снять старые метки.** Удали каждое `🆕` из списка целиком, вместе с ним ничего не трогай: метка всегда стоит вплотную, поэтому после удаления разметка выглядит так, будто её не было.
4. **Добавить видео** в конец списка своего раздела по разметке выше, каждое с `🆕`. Новый раздел — по образцу соседа того же уровня (пустая строка `>` после заголовка, если она есть у соседей).
5. **Пометить цепочку** разделов каждого нового видео по правилу выше.
6. **Проверка** (скриптом, по всему файлу): diff с копией содержит только снятые метки, новые строки и метки цепочек; число `🆕` = новые видео + уникальные разделы в их цепочках; нет двойных пробелов и пробела сразу после `🆕`. Покажи Дмитрию diff.
