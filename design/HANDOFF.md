# Следующий шаг: скрипт сборки PDF (передаточная записка, 2026-11-11)

Дизайн утверждён в `design/mockup.html`: 4 листа, вёрстка написана руками. Нужен скрипт: трекер → HTML по этому макету → PDF. Макет — эталон стилей; CSS берётся оттуда.

## Источник
- Трекер `<obsidianVault>/Life Manager/MDs/MrFrenkie Content.md` (`~/.claude/machine.json` → `obsidianVault`). UTF-8, LF. Только читать.
- Список начинается с первого `# ` после блока кнопок. Frontmatter, кнопки и чекбоксы в PDF не попадают.
- Уровни: `# 🆕🎛️ Раздел` → `## 🆕🥁 Подраздел` → `> [!info] Блок` → `> > [!example] Группа` → `> > ##### Подгруппа`. У Q&A нет `##`.
- Строка: `- [ ] 🆕[Название](url)` (бывает без `[ ] `). После ссылки бывает `([подпись](url))` — связанная ссылка.
- 🆕 у видео → NEW у строки; 🆕 у заголовка → NEW у раздела/блока/группы. Эмодзи заголовков в PDF не выводятся.
- Сверено на 2026-11-11: 228 ссылок, 163 Boosty, 65 YouTube, 5 новых.

## Что выводит PDF (всё есть в макете)
- **Обложка:** «MR. FRENKIE», «Все видео», 5 разделов (ссылки на раздел), «Как пользоваться», цифры, дата, кабели.
- **Содержание:** «Что нового» (путь → якорь группы, название → видео), полоса долей + легенда с числами, оглавление-карточки: русский подзаголовок, подразделы в 2 колонки, число, точки, **настоящий номер страницы**, NEW.
- **Раздел:** контурный номер, название, русский подзаголовок, плашки подразделов (якоря); модуль = `##`, блок = `[!info]` (порт + провод), группа = `[!example]` (панель), подгруппа = `#####` (дорожка с плашкой и числом).
- **Строка:** название-ссылка + бейдж площадки (Boosty/YouTube, тоже ссылка). Пресеты — метка «Пресет», скрипты — «Скрипт» (по названию блока). Связанная ссылка — строка `↳ подпись` со своим бейджем; копия того же видео на YouTube → «Это же видео на YouTube».
- **Серия** (`"…" Series`): метка «Серия» в шапке группы, номер части слева (из названия: «часть 4.5», «#2»).
- Русские подзаголовки: 01 Синтез звука · 02 Аранжировка, теория и жанры · 03 Сведение и мастеринг · 04 Советы и ответы на вопросы · 05 Программы и плагины.
- Кликабельно всё, что выглядит кликабельным (CLAUDE.md, План).

## Правила вёрстки (отработаны на макете)
- Свою разбивку на листы делает скрипт (JS в странице перед печатью): фиксированные листы A4 297 мм, поля 18/16/16/18 мм, низ контента ≤ 281 мм.
- Строка видео никогда не режется; заголовок группы/подгруппы не отрывается от первой строки; группу можно делить по строкам.
- Провод блока: внутри модуля — сплошной, кончается ровно у внутреннего края рамки; снаружи модуля до края листа — пунктир; на новом листе модуль начинается с отступа 4 мм. Класс `cont-down`/`cont-up` в макете.
- Продолжение группы на новом листе — шапка «Название · продолжение» (`h4.cont-h`), выровнена по базовой линии.
- NEW выровнен по центру заглавных букв соседнего текста (сдвиги в макете замерены в Edge, 0,00 px).
- Номера страниц в оглавлении — после разбивки (второй проход).

## Сборка
- Шрифты локальные (`design/fonts`), интернет не нужен.
- `msedge --headless=new --disable-gpu --user-data-dir=<scratchpad> --no-pdf-header-footer --virtual-time-budget=10000 --print-to-pdf=<out> file:///…` — PDF дописывается после выхода команды: ждать изменения файла.
- Превью-панель открывает HTML как `data:` — там не работают локальные шрифты и якоря; проверять в PDF или в Edge.
- Итог: `docs/mr-frenkie-content.pdf`; затем включить GitHub Pages (`main` / `docs`), удалить `Mr. Frenkie Export.md`, поправить README — одним коммитом (CLAUDE.md, План).
- Проверки: число ссылок в PDF = в трекере; внутренние якоря; каждый лист не выше 281 мм; провода у рамок.
